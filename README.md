# 🌌 Egregore: Advanced Topological Alignment Engine (v2.0)

Egregore는 고차원 잠재 공간(Latent Space) 내에서 데이터의 인지 상태 밀도에 따라 구면(Sphere)과 토러스(Torus) 매니폴드를 전 구간 미분 가능한 방식으로 동적 모핑(Morphing)하는 기하학적 정렬 레이어입니다.
Egregore is a geometric alignment layer that dynamically morphs Sphere and Torus manifolds in a fully differentiable manner based on the density of the data's cognitive state within a high-dimensional latent space.

---

## 🚀 아키텍처 진화 개요 (Architecture Evolution Overview: V1 ➡️ V2)

| 기능 (Feature) | 버전 1.0 (v1.0) | 버전 2.0 (v2.0 - Current) |
| :--- | :--- | :--- |
| **차원 확장성**<br>*(Dimension Scalability)* | `[Dim]` 단일 벡터 연산 한계<br>*(Limited to single 1D vectors)* | `[B, S, Dim]` 멀티 배치 파이프라인 완벽 지원<br>*(Full support for multi-batch pipeline)* |
| **토러스 위상 사상**<br>*(Torus Topology Mapping)* | 단순 가중치 선형 결합 구조<br>*(Simple linear combination of weights)* | 차원 분리 및 `Cos/Sin` 기반 독립 위상 고리 구현<br>*(Independent ring mapping via dimension split)* |
| **게이팅 메커니즘**<br>*(Gating Mechanism)* | 고정 상수를 이용한 경직된 임계값<br>*(Rigid thresholding using fixed constants)* | 학습 가능한 `nn.Parameter` 및 수리적 제약 장치<br>*(Adaptive params via `Abs`/`Tanh` constraints)* |
| **최적화 안정성**<br>*(Optimization Stability)* | 문자열 매칭 기반의 불안정한 학습률 제어<br>*(Brittle string-matching based LR control)* | 메모리 `id()` 참조 기반 LLRD 및 가중치 감쇠 제거<br>*(Memory `id()`-based LLRD with weight decay removal)* |

## 🛠️ 핵심 컴포넌트 (Core Components)

### 1. `ProductionEnergyParityLayer`
* **KR**: 모든 차원에서 가중치의 **L2 Norm = 1.0**을 영구 보존하여, 위상 기하 모핑 중 발생할 수 있는 그레디언트 폭발(Gradient Explosion)을 원천 차단합니다.
* **EN**: Preserves **L2 Norm = 1.0** across all dimensions to inherently prevent gradient explosion during topological morphing.

### 2. `BatchResidualHyperNetwork` (Homeostasis Bubble)
* **KR**: 시스템의 항상성(Homeostasis) 유지를 위해 하이퍼네트워크가 생성하는 잠재 공간 변형 폭의 상한선을 **0.1 범위 내로 강력하게 제한**합니다.
* **EN**: Dynamically restricts the latent space perturbation generated by the hypernetwork **within a strict 0.1 boundary** to maintain system homeostasis.

### 3. `ParameterizedTopologyGate` (Adaptive LLRD)
* **KR**: 메모리 주소(`id`) 매칭을 통해 게이트 파라미터를 \(O(1)\) 속도로 안전하게 격리하고, 층별 학습률(Layer-wise Learning Rate)을 백본의 1% 수준으로 제어하여 점진적이고 매끄러운 위상 천이를 유도합니다.
* **EN**: Isolates gate parameters in \(O(1)\) time using memory address (`id`) lookup, applying a 100x lower Layer-wise Learning Rate to guide a stable and smooth topological transition.
